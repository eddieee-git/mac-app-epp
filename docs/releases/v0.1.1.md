## 설치와 업데이트

- **0.1.0을 쓰고 있다면**: Epp를 쓰지 않을 때 알아서 0.1.1로 바뀌어요. 바로 바꾸려면 설정 → 일반 → 업데이트의 **지금 확인**을 누르세요.
- **처음 설치한다면**: 아래 **Epp-0.1.1.dmg**를 내려받아 Epp를 응용 프로그램 폴더로 끌어다 놓으세요. 처음 열 때 경고가 나오면 **완료**를 누른 뒤 시스템 설정 → 개인정보 보호 및 보안 맨 아래의 **그래도 열기**를 누르세요(macOS 14는 오른쪽 클릭 → 열기).

## 새 기능

- **스톱워치**: 시계 창의 **타이머 | 알람 | 스톱워치** 탭에서 써요. 시작·멈춤·계속, **랩**(구간 시간과 전체 시간), 초기화. Epp를 다시 켜도 이어서 재요.
- 스톱워치는 메뉴(타이머 ▸ 스톱워치 시작/멈춤), 메뉴바(타이머·알람이 없을 때 Epp 아이콘 옆에 ⏱ 시간), 빠른 검색(`스톱워치`), 접은 시계에서도 쓸 수 있어요.

## 알려진 제한

- Apple 실리콘 Mac, macOS 14 이상만 지원해요.
- Apple 개발자 서명이 없어서 dmg로 처음 열 때 경고가 나와요.

## English

This version adds a stopwatch to the Timer.

**Installing and updating**
- On 0.1.0, Epp updates itself to 0.1.1 while you aren't using it. To update now, click **Check Now** in Settings → General → Updates.
- New installs: download **Epp-0.1.1.dmg** below and drag Epp into Applications. If macOS blocks the first launch, click **Done**, then **Open Anyway** at the bottom of System Settings → Privacy & Security (on macOS 14, right-click → Open).

**New**
- **Stopwatch**: use the **Timer | Alarm | Stopwatch** tabs in the clock window. Start, stop, resume, **Lap** (split and total times), and reset. It keeps timing even after Epp restarts.
- The stopwatch is also in the menu (Timer ▸ Start/Stop Stopwatch), the menu bar (⏱ time next to the Epp icon when no timer or alarm is showing), Quick Search (“stopwatch”), and the collapsed clock.

**Known limitations**
- Apple silicon Macs with macOS 14 or later only.
- Not signed by Apple, so macOS warns on first launch from the dmg.
