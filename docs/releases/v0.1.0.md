- **처음 설치한다면**: 아래 **Epp-0.1.0.dmg**를 내려받아 Epp를 응용 프로그램 폴더로 끌어다 놓으세요. 처음 열 때 경고가 나오면 **완료**를 누른 뒤 시스템 설정 → 개인정보 보호 및 보안 맨 아래의 **그래도 열기**를 누르세요(macOS 14는 오른쪽 클릭 → 열기).
- 다음 버전부터는 Epp를 쓰지 않을 때 알아서 설치해요. 설정 → 일반 → 업데이트에서 끌 수 있어요.

## 새 기능

- **기능 다섯 개**: 클립보드(옛 Keepy) · 메뉴바(옛 Peeky) · 스티커(옛 Floaty) · 타이머(옛 Clocky) · 캡처(옛 Grabby). 처음에는 모두 꺼져 있어요. 설정 → 일반 → 기능에서 쓸 것만 켜요. 끈 기능은 아무 일도 하지 않아요.
- **메뉴 막대 아이콘 하나**: 아이콘 메뉴에 켠 기능마다 하위 메뉴가 생겨요.
- **설정 한곳**: 왼쪽에 일반과 기능 목록, 위에 설정 검색이 있어요. 기능마다 시작하기 상자, 일반 · (기능 고유) · 단축키 탭이 같은 모양으로 나와요.
- **권한 한곳**: 손쉬운 사용, 화면 기록, 알림, 캘린더를 설정 → 일반 → 권한에서 켠 기능이 필요한 것만 모아 보여 줘요.
- **공통 설정**: 로그인 시 실행, Dock에 아이콘 보이기, 언어(한국어·English), 진단 로그, 데이터 폴더, 업데이트는 일반에 한 번만 있어요.

- Apple 개발자 서명이 없어서 dmg로 처음 열 때 경고가 나와요.

## English

The first version of Epp, which gathers five separate menu bar apps (Keepy, Peeky, Floaty, Clocky, Grabby) into one app as features.

**Installing and updating**
- Download **Epp-0.1.0.dmg** below and drag Epp into Applications. If macOS blocks the first launch, click **Done**, then **Open Anyway** at the bottom of System Settings → Privacy & Security (on macOS 14, right-click → Open).
- From the next version on, Epp installs updates on its own while you aren't using it. Turn this off in Settings → General → Updates.

**New**
- **Five features**: Clipboard (formerly Keepy) · Menu Bar (Peeky) · Stickies (Floaty) · Timer (Clocky) · Capture (Grabby). All start off; turn on the ones you want in Settings → General → Features. Features that are off do nothing.
- **One menu bar icon** with a submenu for each feature you turned on.
- **One Settings window** with General and the features on the left and a settings search on top. Every feature has the same Getting Started box and General · (its own) · Shortcuts tabs.
- **Permissions in one place**: Settings → General → Permissions lists Accessibility, Screen Recording, Notifications, and Calendars only for the features you turned on.
- **Shared settings** (open at login, Dock icon, language, diagnostic log, data folder, updates) appear once, in General.

**Known limitations**
- Data from the old standalone apps (clipboard history, stickies, timers, captures) isn't imported. Epp starts empty.
- Running a feature together with its old standalone app makes shortcuts and menu bar icons clash. Keep only one running.
- Apple silicon Macs with macOS 14 or later only.
- Not signed by Apple, so macOS warns on first launch from the dmg.
