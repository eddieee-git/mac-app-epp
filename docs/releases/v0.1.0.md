Epp 첫 버전이에요. 따로 있던 메뉴바 앱 다섯 개(Keepy, Peeky, Floaty, Clocky, Grabby)를 한 앱의 기능으로 모았어요.

## 설치와 업데이트

- 아래 **Epp-0.1.0.dmg**를 내려받아 Epp를 응용 프로그램 폴더로 끌어다 놓으세요. 처음 열 때 경고가 나오면 **완료**를 누른 뒤 시스템 설정 → 개인정보 보호 및 보안 맨 아래의 **그래도 열기**를 누르세요(macOS 14는 오른쪽 클릭 → 열기).
- 처음 켜면 설정 창이 열려요. 쓸 기능을 켜고, 필요한 권한은 **설정 → 일반 → 권한**에서 한 번에 허용해요.
- 다음 버전부터는 Epp를 쓰지 않을 때 알아서 설치해요. 설정 → 일반 → 업데이트에서 끌 수 있어요.
- 옛 단독 앱을 쓰고 있었다면 같은 기능의 옛 앱은 꺼 주세요(단축키와 메뉴바 아이콘이 겹쳐요). 옛 앱의 기록·스티커·캡처는 가져오지 않아요.

## 새 기능

- **기능 다섯 개**: 클립보드 · 메뉴바 · 스티커 · 타이머 · 캡처. 처음에는 모두 꺼져 있고, 끈 기능은 아무 일도 하지 않아요.
- **한곳에서**: 메뉴바 아이콘 하나(기능마다 하위 메뉴), 설정 창 하나(설정 검색, 기능마다 같은 모양의 시작하기·탭), 권한 한곳, 테마 하나, 진단 로그 하나.
- **빠른 검색 (⌃⌥E)**: 클립보드 기록, 스티커, 캡처 속 글자·메모, 타이머·알람을 한 번에 찾아요. 클립보드 항목을 고르면 앞의 앱에 바로 붙여 넣어요. `5분`(타이머 시작), `새 스티커 …`, `캡처`처럼 바로 실행도 돼요.
- **메뉴바 정리**: 아이콘마다 보이기 / 그룹(어느 그룹인지까지) / 숨기기 중 하나를 골라요.
- **알람 메모**: 알람에 메모를 남기면 울릴 때 함께 보여요.
- **알람 한곳**: 타이머를 켜 두면 스티커 알람도 타이머 알람과 똑같이 울려요(같은 소리, ⌃⌥X로 끄기, 다시 울림). 어느 쪽에서 꺼도 둘 다 꺼져요.
- **스티커로 만들기**: 클립보드 기록 창에서 글을 오른쪽 클릭.
- **타이머 남은 시간**은 Epp 아이콘 옆에 붙어서 메뉴바 아이콘이 늘지 않아요.
- **옮기기**: 설정만, 또는 내용(기록·스티커·캡처·타이머)과 열쇠까지 모두 암호로 잠근 파일 하나로 내보내고 가져와요(새 Mac 등).

## 옛 앱과 바뀐 점

- 단축키 입력, 짧은 알림(복사했어요 등), 관리 창(스티커 관리 · 타이머 목록 · 캡처 보관함)의 모양과 동작을 모든 기능에서 같게 맞췄어요. 관리 창은 크기·자리를 기억하고, Epp를 쓰는 동안 스티커 위에 보여요.
- 메뉴바 기능에서 그룹을 지우면 그 아이콘이 첫 그룹으로 옮겨져요(예전에는 아이콘 바에서 빠졌어요).
- 스티커·타이머·캡처의 번역 사전에 같은 문구가 두 번 들어가도 앱이 꺼지지 않아요.

## 보안

- **클립보드 기록, 잠근 스티커, 캡처 보관함을 암호화**해서 저장해요. 열쇠는 키체인에 있고 Epp만 읽어요.
- 비밀번호 관리 앱에서 복사한 것은 목록에 없어도 기록하지 않아요.
- 고정하지 않은 클립보드 기록은 기본 **30일**이 지나면 지워요(클립보드 설정 → 일반).
- `epp://` 주소로는 창 열기 같은 해가 없는 명령만 받아요. 화면 전체 캡처는 주소로 열지 않고, 몰려오는 주소(10초에 5번 넘게)는 무시해요.
- Epp 전용 인증서로 서명해서, 같은 인증서로 서명한 Epp만 Epp의 권한을 이어받아요(업데이트해도 권한이 그대로예요).
- 업데이트는 서명(Ed25519)·SHA-256·코드 서명을 모두 확인한 뒤에 설치해요.

## 알려진 제한

- Apple 실리콘 Mac, macOS 14 이상만 지원해요.
- Apple 개발자 서명이 없어서 dmg로 처음 열 때 경고가 나와요.
- 옛 단독 앱의 데이터는 가져오지 않아요.

## English

The first version of Epp, which gathers five separate menu bar apps (Keepy, Peeky, Floaty, Clocky, Grabby) into one app as features.

**Installing and updating**
- Download **Epp-0.1.0.dmg** below and drag Epp into Applications. If macOS blocks the first launch, click **Done**, then **Open Anyway** at the bottom of System Settings → Privacy & Security (on macOS 14, right-click → Open).
- Settings opens on first launch: turn on the features you want and allow permissions in Settings → General → Permissions.
- From the next version on, Epp installs updates on its own while you aren't using it (Settings → General → Updates).
- If you used the old standalone apps, quit the ones Epp replaces. Their history, stickies, and captures aren't imported.

**New**
- **Five features**: Clipboard · Menu Bar · Stickies · Timer · Capture. All start off; features that are off do nothing.
- **One of everything**: one menu bar icon, one Settings window with search, one place for permissions, one appearance setting, one diagnostic log.
- **Quick Search (⌃⌥E)** across clipboard history, stickies, text in captures, and timers. Choosing a clipboard item pastes it into the app in front. It can also run things: “5 min” starts a timer, “new sticky …”, “capture”.
- **Menu bar cleanup**: set each icon to Show, Group (and which group), or Hide.
- **Alarm notes** appear when the alarm rings.
- **Alarms in one place**: with Timer on, sticky alarms ring like timer alarms (same sound, ⌃⌥X to stop, snooze), and stopping either stops both.
- **Make Sticky** from clipboard history (right-click).
- The timer's time left sits next to the Epp icon instead of adding a menu bar icon.
- **Move to a new Mac**: export settings only, or everything (content and keys) in one password-locked file.

**Changed from the old apps**
- Shortcut editing, short notices, and management windows (Sticky Manager · Timer List · Capture Library) look and behave the same in every feature.
- Deleting a menu bar group moves its icons to the first group instead of dropping them.

**Security**
- Clipboard history, locked stickies, and the capture library are encrypted on disk; the key is in your keychain and only Epp can read it.
- Password managers are never recorded in clipboard history, even if they aren't in the ignore list.
- Unpinned clipboard history is deleted after 30 days by default.
- `epp://` links only accept harmless commands like opening a window; full-screen capture isn't available by link, and bursts of links are ignored.
- Signed with Epp's own certificate, so only Epp builds signed with it inherit Epp's permissions (they survive updates).
- Updates are verified (Ed25519 signature, SHA-256, code signature) before installing.

**Known limitations**
- Apple silicon Macs with macOS 14 or later only.
- Not signed by Apple, so macOS warns on first launch from the dmg.
- Data from the old standalone apps isn't imported.
